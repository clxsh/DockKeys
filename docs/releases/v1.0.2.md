## DockKeys 1.0.2

用数字快捷键，直达 Dock 中的应用。需要 macOS 13 或更新版本。

### 更新内容

- 中文 README 为默认入口，新增 [完整英文版](https://github.com/clxsh/DockKeys/blob/v1.0.2/README.en.md)和双向切换链接。
- 统一 `.app`、设置窗口和文档图标；菜单栏使用同一图形的单色版本。
- 首次提供 ARM64、Intel 两套 DMG 和 ZIP，以及 SHA-256 校验文件。

### 下载与安装

| 处理器 | 推荐下载 |
|---|---|
| Apple Silicon（M 系列） | `DockKeys-1.0.2-arm64.dmg` |
| Intel | `DockKeys-1.0.2-x86_64.dmg` |

退出旧版，双击 DMG，将 `DockKeys.app` 拖到 `Applications`，然后从“应用程序”打开。ZIP 包含同样的应用，可用于手动安装。

将下载的文件和 `SHA256SUMS.txt` 放在同一目录，执行：

```sh
shasum -a 256 -c SHA256SUMS.txt --ignore-missing
```

### 验证与已知限制

- 19 项核心逻辑检查和 3 项系统热键集成检查通过；ARM64 界面经过本机检查。
- 两种架构的 DMG 和 ZIP 均通过架构、版本、临时签名、统一图标和文件完整性检查；DMG 已挂载验证安装内容。
- Intel 产物为交叉编译，尚未在 Intel Mac 上运行验证。
- **当前产物采用临时签名，尚未经过 Apple 公证。** 如果系统阻止启动，请确认来源和校验值后参考 [Apple 官方打开说明](https://support.apple.com/en-sg/guide/mac-help/mh40616/mac)。
- 应用界面目前为简体中文；多窗口轮换和自动更新暂不支持。

## English

DockKeys launches and switches pinned Dock apps with number shortcuts. Requires macOS 13 or later.

- Chinese remains the default README, with a complete English README and language links.
- The app bundle, settings page and documentation share one icon renderer; the menu bar uses a monochrome version of the same mark.
- DMG and ZIP packages are available for Apple Silicon (`arm64`) and Intel (`x86_64`), with SHA-256 checksums.

Quit any older copy, open the DMG, drag `DockKeys.app` to `Applications`, and open it from Applications. ZIP archives contain the same app. Use the checksum command above to verify your downloads.

**Validation:** 19 core checks and 3 system hotkey checks passed; the ARM64 UI was checked locally. Both architectures' DMG and ZIP contents, architecture, version, signature and icons were verified. The Intel build is cross-compiled and has not been run on an Intel Mac.

**Signing:** These builds are ad-hoc signed and are not notarized by Apple. If macOS blocks opening, verify the source and checksum, then follow [Apple's per-app instructions](https://support.apple.com/en-sg/guide/mac-help/mh40616/mac). The app UI is currently Simplified Chinese.
